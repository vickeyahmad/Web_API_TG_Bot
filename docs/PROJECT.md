# Web_API_TG_Bot

## Goal
Build one centralized B2C digital reseller platform.

## Sales Channels
- AI Tools and Digital Products Website
- Telegram Bot
- SMM Panel
- Admin Panel

All channels must share one backend, database,
catalog, order system, payment system,
and vendor integration layer.

## First Development Target
AI Tools Selling Module (MVP).

Initial features:
- Customer registration and login
- AI Tools product catalog
- Product details and selling prices
- Customer checkout
- Manual payment verification
- Order tracking
- Admin product management
- Admin order management
- Manual vendor fulfillment

## Vendor System
Each product has our own internal product ID.
Multiple vendors may supply the same product.
Customers must never see vendor names,
vendor costs, API keys or routing logic.

## Future Features
- Automatic vendor APIs
- Vendor selection and fallback
- Wallet and payment gateways
- Telegram Bot
- SMM Panel
- Automated fulfillment

## Business Rules
- Use only legitimately sourced products
  and authorized reseller arrangements.
- Never expose supplier credentials.
- Verify payments before fulfillment.
- Store full order and payment history.
- Track vendor cost and profit internally.
